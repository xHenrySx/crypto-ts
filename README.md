# Crypto Trading System

A modern cryptocurrency trading application built with React, TypeScript, and Vite.

## Features

- Real-time cryptocurrency price tracking
- Portfolio management and analysis
- Trading interface with order execution
- Market data visualization and charts
- User authentication and account management

## Tech Stack

- **Frontend**: React 18 with TypeScript
- **Build Tool**: Vite for fast development and optimized builds
- **Styling**: Modern CSS with responsive design
- **State Management**: Context API and custom hooks
- **API Integration**: RESTful services for crypto data

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
4. Open your browser to `http://localhost:5173`

## Development

This project uses Vite's React template with TypeScript support, providing:

- Hot Module Replacement (HMR) for instant updates
- TypeScript type checking
- ESLint for code quality
- Fast build times and optimized production bundles

## Build and Deploy

- Development: `npm run dev`
- Build: `npm run build`
- Preview: `npm run preview`
- Lint: `npm run lint`
